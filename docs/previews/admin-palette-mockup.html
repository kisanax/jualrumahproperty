2Titik tabrakan yang terdeteksi

PARAH Badge status di dark mode susah dibaca
Warna badge hanya diset untuk light (satu set di admin-ui.css). Di dark, teks seperti #047857 (active) dan #b91c1c (suspended) terlalu gelap di atas kartu #171717 — kontras di bawah standar.
draftpending activesold suspended
PARAH 8 hue warna di UI monokrom
Badge memakai 8 keluarga warna berbeda (slate, amber, biru, hijau, ungu, cyan, merah, oranye) di atas palet zinc yang monokrom — jadi satu-satunya sumber "warna" dan terlihat berisik/tabrakan dengan netral.
draftpending readyactive negotiationsold suspended
SEDANG Warna semantik dark terlalu neon
Di dark mode, danger #ff6b5e, success #3ddfa0, warning #fdb022 sangat saturated — berdampingan dengan zinc netral terasa "menyala" dan tidak satu keluarga tone.
Hapus Aktif Review
SEDANG Sisa elemen legacy slate
Beberapa elemen lama masih memakai skala slate (#f1f5f9/#475569, contoh: tombol "Mode Gelap" di topbar) — beda undertone dengan zinc (#f5f5f5/#737373) yang baru, terlihat "bukan satu sistem".
Slate (legacy) Zinc (baru)

3Opsi arah perbaikan

Opsi A
Netral murni
Semua badge jadi netral (abu + dot warna kecil 6px sebagai penanda status). Warna semantik dark dikalemkan ke tone zinc. UI 100% monokrom — paling "shadcn docs".
Paling konsisten · risiko: status kurang menonjol
Opsi B
Netral + status terkendali ★ rekomendasi
Badge tetap berwarna tapi di-resep: satu saturasi, teks lebih terang di dark mode (variant khusus dark), jumlah hue dipangkas 8 → 4 (netral, amber, hijau, merah). Semantik tetap terbaca sekilas.
Keseimbangan konsistensi & keterbacaan status
Opsi C
Netral + 1 aksen tunggal
Seperti shadcn base "blue/slate": nav aktif, focus ring, dan link memakai SATU warna aksen (mis. biru #2563eb), sisanya tetap zinc. Badge ikut Opsi B.
Lebih "bernyawa" · keluar dari netral murni
